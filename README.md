# Café com Deploy

Projeto individual de sistematização da disciplina Integração e Entregas Contínuas, da pós-graduação em Engenharia DevOps do CEUB.

O objetivo é construir uma API para o catálogo de cafés e demonstrar um processo de integração e entrega contínuas com testes, ambientes separados e evidências verificáveis.

Este repositório está em preparação. O Relatório de Voo e as instruções de execução serão acrescentados ao longo do trabalho.
